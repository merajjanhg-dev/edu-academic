# فرادان | FARADAN

وب‌سایت فارسی فرادان؛ طرح اولیهٔ یک مرجع علمی و آموزشی با هویت بصری اختصاصی.

## فایل‌ها
- `index.html`: ساختار صفحه
- `styles.css`: طراحی واکنش‌گرا و راست‌چین
- `script.js`: منوی موبایل و جست‌وجوی اولیهٔ دسته‌بندی‌ها

## انتشار با GitHub Pages
1. این فایل‌ها را در ریشهٔ مخزن GitHub قرار دهید.
2. وارد **Settings → Pages** شوید.
3. در بخش Build and deployment گزینهٔ **Deploy from a branch** را انتخاب کنید.
4. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و Save کنید.
5. پس از چند دقیقه آدرس سایت در همان صفحه ظاهر می‌شود.

## وضعیت نسخه
این نسخه رابط کاربری اولیه است و هنوز به پایگاه داده، پنل مدیریت، احراز هویت امن یا کنترل دسترسی محتوای پولی متصل نیست. این امکانات باید در مرحلهٔ بعد با یک سرویس بک‌اند و پایگاه داده پیاده‌سازی شوند.

## نکتهٔ مهم برای بازکردن در گوشی
برای مشاهدهٔ درست، هر سه فایل `index.html`، `styles.css` و `script.js` را از ZIP استخراج کنید و در یک پوشه نگه دارید؛ سپس `index.html` را باز کنید. اگر برنامهٔ فایل‌خوان گوشی اجازهٔ دسترسی به فایل CSS کنار HTML را ندهد، پیش‌نمایش محلی ممکن است همچنان ناقص باشد. روش مطمئن‌تر، انتشار در GitHub Pages است.
